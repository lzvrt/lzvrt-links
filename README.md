# lzvrt-links

Personal links page for lzvrt / мораль.

## Music

Place MP3 files in `music/` using these names:

- `track-01.mp3`
- `track-02.mp3`
- `track-03.mp3`
- `track-04.mp3`

The page chooses one of the four tracks at random on launch.

## GitHub Pages

Publish from the `main` branch and the repository root. As a project repository, the site URL will be `https://lzvrt.github.io/lzvrt-links/`.
